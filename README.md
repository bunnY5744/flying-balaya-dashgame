# Balayya Bottle Dash

A single-file HTML game — **Balayya Bottle Dash**.

Tap / Space to fly, avoid the bottles, and beat your best score.

## Play

- Open `index.html` in a browser, or
- Enable GitHub Pages for this repo (Settings → Pages → Deploy from branch `main`, folder `/`) and play the live link.

## Files

- `index.html` — playable copy (same game, browser-ready name)
- `flying-balaya-dash-game.html` — original uploaded file, unchanged
